# Quote API

A RESTful Quote API built using Java, Spring Boot, Spring Data JPA, and MySQL.

This project allows users to create, read, update, and delete quotes through REST API endpoints.

## 🚀 Features

- Create a new quote
- Get all quotes
- Get a quote by ID
- Update an existing quote
- Delete a quote
- Store quotes in MySQL
- Test APIs using Postman

## 🛠️ Tech Stack

- Java 21
- Spring Boot
- Spring Web MVC
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Postman
- Git & GitHub
